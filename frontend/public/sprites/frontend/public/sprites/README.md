# Спрайти транспорту

По одному реальному фото на кожен вид транспорту:

- `metro-1.jpg` — метро
- `tramvay-1.jpg` — трамвай
- `trolley-1.jpg` — тролейбус
- `bus-1.png` — автобус

Це фотографії, а не розкадровка під кути (`framesCount/cols/rows = 1` у
`src/config/transportSprites.ts`), тож зображення не обертається на 360° —
напрямок руху позначається окремим трикутником-курсором. Пропорції
(`frameWidth` / `frameHeight`) мають збігатися з реальним розміром файлу,
а `displaySize` задає розмір відображення на карті/картці маршруту.

Резервні альтернативні фото (`bus-2.png`, `metro2-1.jpg`, `tramvay2-1.jpg`)
лежать поруч і не підключені — можна замінити основний файл або додати
новий вид, якщо потрібно.

Поки файл відсутній або не завантажився — застосунок автоматично показує
акуратний геометричний маркер-фолбек, карта лишається повністю робочою.

Номер маршруту та кінцева зупинка НЕ малюються на самому фото — вони
рендеряться окремо компонентом `<RouteDisplay />` поверх транспорту.
